## 🚀 Мой стек технологий

Я использую только самые современные и эффективные инструменты для создания качественных веб-приложений:

- **React** — библиотека для построения динамичных, высококачественных интерфейсов.
- **Vite** — быстрый инструмент для сборки, который значительно ускоряет разработку.
- **Tailwind CSS** — utility-first CSS framework для быстрого создания адаптивных интерфейсов.
- **Bootstrap** — популярный фреймворк для создания красивых и отзывчивых сайтов.
- **JavaScript** — основной язык программирования для логики на клиентской стороне.
- **HTML/CSS** — основа веб-разработки для структуры и стиля.
- **Sass** — расширение CSS для более мощных стилей.
- **Figma** — для дизайна и прототипирования интерфейсов.
